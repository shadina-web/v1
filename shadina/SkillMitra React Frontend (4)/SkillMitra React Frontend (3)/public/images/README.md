# Indian Profile Images

This folder contains placeholder images for Indian users.

## Image Sources

All images are sourced from Unsplash (free to use):
- https://unsplash.com

## Usage

Images are loaded dynamically from the `indianImages.ts` utility file.

## Categories

1. **Men Profiles** - Professional Indian men
2. **Women Profiles** - Professional Indian women  
3. **Workers** - Indian service workers and professionals
4. **Services** - Service category images (carpentry, plumbing, teaching, etc.)

## Note

The app uses Unsplash API to load images dynamically, ensuring high-quality, diverse representation of Indian users.
