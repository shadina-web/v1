⚠️ Important: Make sure to use jdbc:h2:mem:skillmitra exactly as shown. Do NOT use jdbc:h2:~/test or any file path!
3 Click "Connect" Button

After entering the connection details, click the blue "Connect" button in the H2 Console.

4 Try Sample Queries

After connecting, try these SQL queries:

View all users:

SELECT * FROM users;

View all skills:

SELECT * FROM skills;

Show all tables:

SHOW TABLES;

Count registered users:

SELECT COUNT(*) as total_users FROM users;

View user details with pretty formatting:

SELECT 
    id, 
    name, 
    email, 
    phone, 
    location,
    created_at
FROM users 
ORDER BY created_at DESC;
🔧 Troubleshooting
Error: "Database not found"
➜ Make sure you're using jdbc:h2:mem:skillmitra (with mem:)
➜ Check that backend is running on port 8082
Error: "Connection refused"
➜ Backend is not running. Start it with: mvn spring-boot:run
Error: "Wrong user or password"
➜ Username must be: sa (lowercase)
➜ Password must be: empty (no password)
