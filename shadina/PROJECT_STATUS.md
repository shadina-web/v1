## 🗄️ Database Schema

### Tables Created (Auto-generated by Hibernate)

#### 1. **users** Table
```sql
CREATE TABLE users (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,     -- Bcrypt hashed
  phone VARCHAR(20),
  location VARCHAR(255),
  bio TEXT,
  skills TEXT,                        -- JSON array as text
  interests TEXT,                     -- JSON array as text
  preferred_language VARCHAR(10),
  avatar VARCHAR(255),
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

#### 2. **skills** Table
```sql
CREATE TABLE skills (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  description TEXT,
  category VARCHAR(100),
  created_at TIMESTAMP
);
```

```sql
CREATE TABLE jobs (
```

## 🔐 Authentication Flow

```
┌─────────────────────────────────────────────────────────┐
│                   REGISTRATION FLOW                      │
└─────────────────────────────────────────────────────────┘
User fills signup form
        ↓
POST /api/auth/register
        ↓
Backend validates data
        ↓
Password hashed with Bcrypt
        ↓
User saved to database
        ↓
Success response returned
        ↓
User redirected to login

┌─────────────────────────────────────────────────────────┐
│                      LOGIN FLOW                          │
└─────────────────────────────────────────────────────────┘
User enters credentials
        ↓
POST /api/auth/login
        ↓
Backend verifies password
        ↓
JWT token generated (24h expiry)
        ↓
Token sent to frontend
        ↓
Token stored in localStorage
        ↓
User redirected to dashboard

┌─────────────────────────────────────────────────────────┐
│                  AUTHENTICATED REQUEST                   │
└─────────────────────────────────────────────────────────┘
User makes request (e.g., update profile)
        ↓
Axios interceptor adds header:
Authorization: Bearer <token>
        ↓
Backend validates JWT token
        ↓
Request processed
        ↓
Database updated
        ↓
Response sent back
        ↓
Frontend updated
```

## 🐛 Troubleshooting

### Backend Issues

**Issue**: Port 8082 already in use
```bash
# Find process using port 8082
netstat -ano | findstr :8082

# Kill process (replace PID)
taskkill /PID <PID> /F

# Restart backend
cd skillmitra-backend
mvn spring-boot:run
```

**Issue**: Database connection failed
- Check application.properties has correct JDBC URL
- Verify H2 dependency in pom.xml
- Look for HikariCP errors in logs

### Frontend Issues

**Issue**: Port 3000 already in use
```bash
# Find and kill process
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# Restart frontend
cd "SkillMitra React Frontend (3)"
npm run dev
```

**Issue**: API calls failing
- Check VITE_API_URL in .env file
- Verify backend is running on port 8082
- Check CORS configuration in SecurityConfig.java
- Open browser DevTools → Network tab for details

### Database Issues

**Issue**: Can't connect to H2 Console
- Verify JDBC URL: `jdbc:h2:mem:skillmitra` (with `mem:`)
- Username: `sa` (lowercase)
- Password: leave empty
- Make sure backend is running first

**Issue**: Tables not created
- Check spring.jpa.hibernate.ddl-auto=update
- Look for Hibernate errors in backend logs
- Verify entity classes have @Entity annotation
